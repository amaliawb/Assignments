# Day 01 – Personal Website

For this assignment, I created a personal website using **GitHub Pages and Jekyll**. Since I hadn't used these tools before, I used **ChatGPT** to help me understand what to do and guide me through the process.

## How I Used AI

I started by asking ChatGPT to give me **step-by-step instructions** for creating the website in my GitHub repository. It told me which files I needed to create, what to put in them, and where everything should go.

I then asked ChatGPT to help me make the page look more like an actual personal website. It suggested a structure for the page and helped me create sections for information about myself, my studies, and my interests. I changed and adapted the text to fit what I wanted on my website.

I also asked how to **add a picture** to the website. ChatGPT explained where to upload the image in my repository and how to add it to the page.

When I made changes to my files but they **didn't show up on the website**, I used ChatGPT to figure out what was wrong and what I needed to check or change.

Finally, I asked ChatGPT to explain **what Jekyll actually does**, because I had followed the instructions but wanted to understand what was happening. It explained that Jekyll takes the files I write and turns them into the website that GitHub Pages displays.
